# mividacomoluna.com

One world, two perspectives: Linder's **Colors** and Luna's **Goth**.

- **Linder DAE / Amanda Bellaford:** the colorful host, music and events.
- **Luna:** the gothic world of lunar cycles, symbolism and written readings.

## Design handoff

The current Colors/Goth direction and reading-experience frontend, implemented
by **Sophie DAE**, are approved for continuation under **Linder DAE**.
Sophie's original work and commit attribution remain intact.

This is approval of the design direction, not certification of payment,
authentication or backend readiness. The public reading sample is editorial;
personalized paid readings, credits and checkout are not yet enabled.

The static website lives in `docs/` and uses HTML, CSS and JavaScript.
